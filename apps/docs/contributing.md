# Contributing

Contributions are welcome when they preserve Conduit's local-first and deny-by-default model.

Before coding, search existing issues and describe larger design changes. Security boundaries, new browser permissions, remote transports, and protocol changes need an explicit threat analysis.

Each pull request should be focused, documented, tested at the appropriate layer, and pass formatting, lint, type checking, tests, builds, and docs validation. Never include real browser data or credentials in fixtures.

See the repository [contribution guide](https://github.com/err0rgod/conduit/blob/main/CONTRIBUTING.md), [code of conduct](https://github.com/err0rgod/conduit/blob/main/CODE_OF_CONDUCT.md), and [security policy](https://github.com/err0rgod/conduit/blob/main/SECURITY.md).
